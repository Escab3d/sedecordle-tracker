Set up sync

Games sync through one secret gist in your GitHub account. Every device you connect (the desktop extension, the phone web app) reads and writes it automatically.

  1. Open GitHub → new fine-grained token.
  2. Name it, for example, Sedecordle Tracker – phone, and pick an expiration.
  3. Repository access: choose Public repositories. The tracker needs no repository access.
  4. Permissions → Account permissions → Gists: set to Read and write. Nothing else.
  5. Generate the token, copy it, and paste it below.

The token is stored only in this browser on this device, and it can only read and write your gists. Use a separate token per device, so you can revoke one at github.com/settings/personal-access-tokens without affecting the others. Note: the web app shares its storage with any other site you publish under the same *.github.io address.

How it works

  • When it syncs: automatically when you open the tracker, after saving a game from the bookmarklet, and (in the extension) when a game finishes. You can also tap Sync now.
  • Merging: game by game. Timings recorded on any device are kept, and a game you continued elsewhere is extended rather than duplicated.
  • Deleting a game deletes it on every synced device.
  • The gist: secret gists are unlisted, but anyone with the gist's exact address could read your game data. It holds only your games, never the token.
