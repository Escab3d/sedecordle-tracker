You're in the extension

The extension records games by itself. This page sets up the bookmark used by the web app (for browsers without extensions, such as Chrome on Android).

1. Check that bookmarklets work

Bookmark this test the same way as in step 2, open any page, and run it. You should see a message.

2. Add the tracker bookmark

Version:

Sedecordle Tracker ← on a computer, drag this to the bookmarks bar

Android Chrome

  1. Tap Copy bookmark code.
  2. Bookmark this page: ⋮ → ☆.
  3. Open ⋮ → Bookmarks, find the new bookmark, choose Edit.
  4. Name it sedtrack, and replace the URL with the copied code.
  5. On sedecordle.com, tap the address bar, type sedtrack, and tap the bookmark suggestion (the one with the star icon, not a search).

3. Using it

  • After a game: run the bookmark and tap Save to tracker. The game opens here and is saved on this device.
  • For guess timings: also run it once before your first guess. Every guess after that gets a time, until the tab is reloaded.
  • The site keeps today's daily until tomorrow, and the current free game until you start a new one. Save before then.
  • Saving the same game twice is safe: it's merged, and timings are kept.

4. This device

Checking storage…

To install: open the browser menu → Add to Home screen / Install app. Games are stored only in this browser on this device. Use Game log → Export JSON for backups or to move them to the desktop extension (Import JSON there).
